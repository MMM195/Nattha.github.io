About

สวัสดีครับ ผมชื่อ ณัฐกิตติ์ สำลีปั้น ปัจจุบันกำลังศึกษาที่ สถาบันการจัดการปัญญาภิวัฒน์ (PIM) คณะวิศวกรรมศาสตร์และเทคโนโลยี สาขาเทคโนโลยีดิจิทัลและสารสนเทศ (DIT)

ปัจจุบันทำงานพาร์ทไทม์ที่ Gosoft ในตำแหน่ง IT Store Support มีประสบการณ์ด้านการแก้ไขปัญหาระบบคอมพิวเตอร์ Remote Support และดูแลอุปกรณ์ภายในร้าน

สนใจด้าน Web Development, IT Support, HTML, CSS, JavaScript และ Java พร้อมเรียนรู้เทคโนโลยีใหม่ ๆ เพื่อพัฒนาทักษะอยู่เสมอ
